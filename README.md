# 🎯 Mega Akula — Promotional Website

A modern, full-stack promotional website built with **React (Vite)**, **TailwindCSS**, and a custom **Node.js backend**.  
Designed as a marketing platform for **Mega Akula**, it provides an interactive lottery system, real-time order handling, and a sleek user experience.

🌐 **Live Demo**: [Mega Akula Website](http://mega-akula.work.gd/)

---

## 🚀 Features

- 🎁 **Lottery Game** — users can pick from **3 prizes**.  
- 💯 **100% Discount Offers** — limited-time promotional deals.  
- 📝 **Order Form** — customers leave their **name + phone number**, and the data is processed by the backend service.  
- 📊 **Backend Integration** — all orders are handled via `service/index.js`.  
- 🎨 **Modern Design** — responsive, minimal, and elegant TailwindCSS UI.  
- ⚡ **Live Updates** — instant handling of user inputs and offers.  

---

## 🛠️ Tech Stack

- **Frontend**: React, Vite, TailwindCSS  
- **Backend**: Node.js (Express in `service/index.js`)  
- **Deployment**: Production-ready build

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Alazizxan/Mega-Akula-reklam.git
cd Mega-Akula-reklam
```

Install dependencies:

```bash
npm install
```

Run development server (frontend + backend):

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Serve production build:

```bash
npm run preview
```
